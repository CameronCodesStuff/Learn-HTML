# Learn-HTML
Simple guide for learning HTML for users with short focus.

```text
Learn-HTML/
  ├── index.html
  ├── script.js
  ├── style.css
```
---
## How do I learn?
Learn-HTML aims to teach the absolute basics of HTML, for beginners who have never typed a line of code in their life. Learn-HTML gives you a dead simple guide to follow, then lets you experiment on your own.

[Live Site](https://cameroncodesstuff.github.io/Learn-HTML/)
Follow the instructions on the left hand side and complete missions. 

### Publishing
If you wish to publish the site you made onto GitHub pages, then you can follow this [guide](https://cameroncodesstuff.github.io/tutorial/). The guide has step by step instructions + images showing you how to make your website live for everyone to see!
